04 / The model, without the mystery

Simulate, inspect, forecast. Never fit.

Three pieces make tomorrow.

ε[t] = √h[t] × z[t]. Then h[t+1] = ω + αε[t]² + βh[t]. Start h[1] at target σ² and set ω = target σ² × (1 − α − β). α and β are nonnegative, with α + β ≤ 0.99. The target is a variance expectation under unit-variance innovations, not a cap or an average guaranteed in this sample.

Positive and negative shocks of equal size have identical variance effects. This symmetric model has no leverage effect. α = 0 ignores every innovation, leaving variance at its target from this initialization.

Forecast the variance gap.

At the selected period's end, h[t+1] is known. For k ≥ 1, E[t]h[t+k] = target σ² + (α + β)^(k−1) × (h[t+1] − target σ²). The chart takes its square root. Gap half-life = log(0.5) / log(α + β); at zero persistence it is not applicable and forecasts reset from horizon 2.

The expected variance gap decays with α + β, not β alone. A noisy realized variance path need not decay monotonically. Initializing at the target is not a draw from the stationary distribution; no burn-in is used.

Invented innovations, visible limits.

A seeded xorshift32 sequence produces uniform-like innovations in [−√3, √3), scaled for the ideal uniform distribution's unit variance. Shock modes replace z[181] with +4 or −4. All other innovations stay identical. The intervention breaks the ordinary innovation law at that one period; forecasts do not anticipate another intervention.

Zero conditional mean, known parameters, abstract return residuals. No prices, calibration, estimation, likelihood, parameter uncertainty, market data, annualization or predictive validation. Not a normal or Student-t simulation. Educational illustration, not investment advice.
